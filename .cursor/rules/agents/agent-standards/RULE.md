# Agent Standards

Shared rules all agents follow.

## Scope
- Attribution for docs/logs
- Announcement format
- Canonical agent names

## Rules
- Docs/logs: add author + date when work is substantial; skip trivial/config
- Code: add `@author` block only for non-trivial logic
- Announcement format (orchestrator): `🕵️‍♂️ Agent <Name> started working on <task>`
- Canonical names: WebGPU Engineer, Surface Engineer, Input Engineer, Accessibility Engineer, Agent Ruler, Build Orchestrator

## When This Applies
- Any agent work, docs/logs, or orchestrated invocation

## Checklist
- [ ] Attribution added when needed
- [ ] Correct agent name used
- [ ] Announcement format followed
